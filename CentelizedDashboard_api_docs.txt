1. ARCHITECTURE & MULTI-TENANCY OVERVIEW
================================================================================
- Primary Keys: UUIDv4 across all models.
- Timestamps: UTC `created_at` and `updated_at`.
- Multi-Tenancy: Scoped to `Organization` via `TenantScopedModel` and `TenantScopedViewSetMixin`.
- Dual Serializer Pattern: Read serializers return deep nested hierarchies (with `select_related`),
  Write serializers accept foreign key identifiers.

2. AUTHENTICATION & IAM ENDPOINTS
================================================================================
POST   /api/v1/auth/login/
  Request Payload:
  {
    "email": "marcus.vance@ila-command.com",
    "password": "Admin@123456"
  }
  Response:
  {
    "access": "<jwt_access_token>",
    "refresh": "<jwt_refresh_token>",
    "user": {
      "id": "<user_uuid>",
      "email": "marcus.vance@ila-command.com",
      "profile": { ... },
      "employee": { ... },
      "role": "CEO"
    }
  }

POST   /api/v1/auth/refresh/
  Request Payload:
  {
    "refresh": "<jwt_refresh_token>"
  }

GET    /api/v1/auth/me/
  Response: Returns active user profile, linked employee profile, role code, and permission matrix.

POST   /api/v1/auth/switch-role/
  Request Payload:
  {
    "role": "HR_MANAGER"
  }
