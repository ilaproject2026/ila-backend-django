      "lease_end_date": "2029-06-01"
    },
    "rooms_count": 20
  }

  Description: This endpoint atomically creates:
    1. A MasterLease record
    2. A Property record linked to the lease
    3. N individual Room records (based on rooms_count)

    - Rent amounts vary by index for realistic pricing

  Response: 201 Created
