CUSTOM ACTION: Advance Milestone
─────────────────────────────────
  POST /api/v1/import-export/transactions/{id}/advance-milestone/

  Description: Advances the consignment through 5 milestone stages.
  Each stage automatically recalculates escrow progress and release amounts.

  Stage Progression:
    Stage 1 → Stage 2: 20% payout, escrow progress = 25%
    Stage 2 → Stage 3: At sea, escrow progress = 50%
    Stage 3 → Stage 4: 70% cumulative payout, escrow progress = 75%
    Stage 4 → Stage 5: 100% settled, escrow progress = 100%

  Response: Updated Transaction object

CUSTOM ACTION: Sign Vault
──────────────────────────
  POST /api/v1/import-export/transactions/{id}/sign-vault/

  Request Body:
  {
    "signerRole": "CEO"
  }

  Description: Registers a cryptographic multi-sig signature on the 3-of-4 escrow vault.
  Response: Updated Transaction object

  COMMON NOTES
================================================================================

  • Authentication: All endpoints use AllowAny (public access) in development; JWT Bearer in production.
  • Identifier Mapping: All endpoints seamlessly accept and return both human-readable IDs ('IMP-9201', 'TX-90412') and UUIDs.
  • Pagination: DRF default pagination applies.
  • Content-Type: application/json
  • Date Format: ISO 8601 (YYYY-MM-DDTHH:MM:SSZ)
  • All ViewSets support the DRF browsable API at each endpoint URL.
  • DefaultRouter auto-generates API root index at /api/v1/import-export/
