1. GLOBAL HTTP CLIENT & AUTHENTICATION PROTOCOL
================================================================================

Configure your Vite Axios client (`src/services/api/client.ts`):
Base URL:
  const API_BASE = import.meta.env.VITE_API_BASE_URL || 'http://127.0.0.1:8000/api/v1';

All authenticated requests automatically include the Bearer token in the header:
  Authorization: Bearer <ACCESS_TOKEN>

Frontend Area Hook Implementation:
```typescript
// src/hooks/useDashboard.ts
import { useState, useEffect } from 'react';
import apiClient from '../services/api/client';

export function useDashboard() {
  const [data, setData] = useState(null);
  const [loading, setLoading] = useState(true);

  useEffect(() => {
    apiClient.get('/corporate-admin/analytics/dashboard/')
      .then(res => setData(res.data))
      .finally(() => setLoading(false));
  }, []);

  return { data, loading };
}
```

     }

     (Also at: GET /api/v1/auth/me/)
     Response:

       "email": "marcus.vance@ila-command.com",
       "full_name": "Marcus Vance",

     POST /api/v1/corporate-admin/opportunities/{id}/stage/

     Query Filter: ?stage=SCREENING
  2. POST /api/v1/corporate-admin/candidates/
  3. POST /api/v1/corporate-admin/candidates/{id}/stage/
     Payload: { "stage": "ONBOARDING" }

      of an Onboarding case in the Onboarding system with a standardized 4-step checklist.

8. AREA 7: ONBOARDING WORKFLOW & CHECKLIST SIGN-OFF
================================================================================
Corresponding Frontend Area:
  Files: `src/pages/Onboarding.tsx`, `src/components/onboarding/OnboardingStepper.tsx`
  Purpose: Tracking document collection, hardware allocation, accounts setup, and final HR sign-off.

API Endpoints:
  1. GET /api/v1/corporate-admin/onboarding/
  2. POST /api/v1/corporate-admin/onboarding/{id}/step/
     Payload:
     {
       "current_step": "HARDWARE_PROVISIONING",
       "progress": 75,
       "checklist": [
         { "id": "1", "title": "Verify Credentials", "completed": true },
         { "id": "2", "title": "Tax & Payroll Setup", "completed": true },
         { "id": "3", "title": "Executive Sign-off", "completed": true },
         { "id": "4", "title": "Hardware Provisioning", "completed": false }
       ]
     }

  3. POST /api/v1/corporate-admin/onboarding/{id}/sign-off/
     Payload: (Empty body)
     *NOTE: Sets onboarding progress to 100%, status to 'COMPLETED', approval to 'APPROVED',
      and automatically provisions a new active Employee and Profile record in the directory!

================================================================================
